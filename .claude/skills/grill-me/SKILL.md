Interview me relentlessly about every aspect of this plan until we reach a shared understanding.

How to run the session:

1. Start by restating the plan in one or two sentences so we agree on what is being grilled. If no plan has been given yet, ask for it first.
2. Walk down each branch of the decision tree. Resolve dependencies between decisions one by one: settle the upstream decision before asking about anything that depends on it.
3. Ask questions one at a time. Never batch several questions into one message.
4. For every question, include your own recommended answer and a short reason for it, so I can simply agree, tweak, or push back.
5. If a question can be answered by exploring the codebase or the files at hand, explore them instead of asking me.
6. Challenge weak spots (hidden assumptions, missing edge cases, unclear ownership, unrealistic timelines, unmeasured outcomes), but stay constructive and warm.
7. Keep going until every branch is resolved. Then give a concise summary of the decisions made, the open risks, and the agreed next steps.
